# 06 — Roadmap (not implemented)

The next planned milestone is two-hand pinch-to-zoom. It requires reading a second set of hand landmarks, identifying pinch state per hand, and mapping the separation of two pinched hands to a bounded model scale.

After that: X/Y free rotation, gesture stabilization and hysteresis, Blender `.glb` loading via `GLTFLoader`, a polished interface, and more stable two-hand tracking.

These are future exercises, **not** features claimed by the v0.3 demo.
